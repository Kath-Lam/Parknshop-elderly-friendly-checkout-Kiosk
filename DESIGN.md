# Current reference lock: familiar-layout accessibility improvements

User instruction (2026-11-18): retain the original interface as much as possible because many older shoppers have tried it already. This takes precedence over the earlier three-step redesign.

Primary visual target: the five supplied PARKnSHOP photographs and the preserved original/ implementation. Preserve desktop spatial anchors except where the latest sketch specifies changes: white receipt left, bags/produce right, green total below receipt, and bottom-right Pay. The current shopping screen uses the supplied hand-drawn sketch: membership top-right; five table columns; inline minus/plus controls; Back and Staff help at the bottom. Payment choices replace the right panel while the receipt remains visible.

Use direct, incremental edits. Do not introduce a mandatory review page, replace the visual identity, move familiar controls into a new navigation scheme, or remove existing payment methods.

Changes: larger primary and secondary transaction text, larger controls, Chinese product names first, explicit subtotal and savings above the existing totals, clearer Start hint, staff help highlighted in its original location, optional larger text/read aloud, undo removal, dialog keyboard focus recovery. The default flow remains start → scan/add → pay → choose method → simulated confirmation.

Narrow screens may stack the existing regions to avoid reducing critical text to tiny sizes; this is a fallback for phones, not the main Mac kiosk target. Enlarged type increases the kiosk's height rather than clipping controls.

References: project Findings (four interviews); supplied kiosk photos; W3C Older Users and Web Accessibility; WCAG 2.2 contrast and enhanced target size guidance. Detailed sources, reasoning and remaining usability validation are in AGE-FRIENDLY-NOTES.md.

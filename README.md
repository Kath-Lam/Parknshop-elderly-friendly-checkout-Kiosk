# 百佳自助付款機：保留原版介面的長者友善修改

保留照片中的操作介面及流程，再改善閱讀及操作。這是學生原型，並非百佳官方系統；所有付款及求助均為模擬，沒有實際扣款或通知職員。

## 在 Mac 開啟

雙擊 `Start.command`，保持啟動視窗開啟，瀏覽器會開啟 http://localhost:4173 。需要 Python 3，網頁本身無須安裝套件。若不能直接開啟，可在終端機切換至此資料夾，執行 `python3 server.py --open`。不要直接雙擊 index.html。

## 操作方式

首頁已移除促銷背景、SoSIM、右上會員優惠及「其他功能」，保留並放大原順序的「查詢價格」、「易賞錢」、「開始」。

1. 按原位的「開始」，再按畫面下方的示範商品加入購物清單。
2. 也可按「載入照片示例」：兩盒藍莓，原價 $32，減 $8，總額 $24。
3. 商品清單依草圖分為「商品名稱、單價、數量、加／減、金額」五欄。按每行的 −／＋ 修改數量；最後一件移除前會確認，移除後可復原。
4. 會員資料及登入入口放在右上方；購物袋加減放在右側；蔬果／無條碼移至商品清單下方。購物袋預設 0，會員可以略過。
5. 清單下方分列商品原價、優惠減免、貨品件數、膠袋數量及綠色總額。底部是「返回首頁」及「蔬果／無條碼」，黃色「職員協助」固定於右上角；右側膠袋下方為直向大「付款」按鈕；返回首頁會保留商品。
6. 在原位選擇八達通、電子錢包、卡或禮券等。確認視窗再次顯示金額；按「完成模擬付款」才顯示完成。返回會保留商品。

## 網站內置商品資料庫

商品資料集中儲存在 `product-database.js`，包括商品編號、展示條碼、中英文名稱、價格、圖片、分類及啟用狀態。商品按鈕、查詢價格、購物清單和金額計算都使用同一份資料。

目前的 `barcode` 是課堂展示編號。取得實際商品包裝上的條碼後，只需在 `product-database.js` 更換相應數字；價格以港幣「分」儲存，例如 `2350` 代表 HK$23.50。`productByBarcode()` 可供之後的鏡頭條碼掃描功能直接查找商品。未知條碼不會加入購物清單。

## 改善了甚麼

保留藍色畫面、左側清單、右側購物袋和蔬果功能、綠色總額及右下付款。開始後的商品頁按最新手繪草圖調整：每行可直接加減數量，會員移至右上，底部保留返回及蔬果／無條碼，右側保留付款，職員協助固定右上角。主要文字與按鈕放大，職員協助用黃色突出。付款頁沿用相同五欄商品表格、右上會員和總額區，右側顯示原有付款方式。數量加減在付款頁鎖定，按左下「返回」即可繼續修改。

頁頂提供「放大文字」及「朗讀提示」。語音使用裝置及瀏覽器功能，中文指定 zh-HK，聲線與播放是否成功取決於 Mac 的語音支援；沒有自動播放。

預設電腦介面保留左右分區；手機等窄畫面為了避免縮成小字，允許上下排列。放大字體時付款機會增高，可垂直捲動。

頁底「查看修改前版本」開啟 original/，方便比較。這次修改已取代先前的三步流程版。

## 會員電話及二維碼登入

點選「易賞錢」或「登入會員」，會顯示左側即時鏡頭掃描、右側電話輸入鍵盤。

- 第一次開啟時，請允許瀏覽器使用鏡頭。內置鏡頭會顯示實時畫面，將手機上的二維碼對準框內。
- 讀到二維碼後會以綠色提示，再按「確認二維碼示範登入」。不會把二維碼當作網址開啟。這只表示成功讀到二維碼，不代表驗證了真實易賞錢會員。
- 電話可點數字鍵或用實體鍵盤輸入。示範可用 `12345678`，香港電話採 8 位數字。
- 電話與鏡頭影像只在目前瀏覽器處理，不上傳、不寫入儲存空間。登入後只保留電話末四位的遮罩或「二維碼示範登入」標記。
- 關閉、略過、登入完成、切換背景或離開頁面會停止鏡頭。拒絕權限或找不到鏡頭時仍可用電話登入。
- 真實會員驗證及積分查詢需要易賞錢授權系統，本原型沒有串接；133 積分仍為示範數字。
- QR 解碼使用隨網頁附帶的 jsQR 1.4.0，MIT 授權見 vendor/jsQR-LICENSE.txt；執行時不需外部 QR 服務。

測試以模擬鏡頭影片確認實際 QR 解碼、即時畫面、重掃、電話按鍵、權限拒絕後備、登入及 Escape 關閉時鏡頭停止。仍需在展示用 Mac 試用實際內置鏡頭的對焦及清晰度。
